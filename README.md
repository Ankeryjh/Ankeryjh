## 03 WHAT I'M BUILDING

<sub>CURRENTLY BUILDING / PRACTICAL AGENT SYSTEMS</sub>

### Local AI Learning System

A local-first path from model chat to a controlled Agent: **Ollama → Embedding → Qdrant → RAG → Query Rewrite → Tool Calling → Agent Harness → Session Memory → Web Agent → Trace UI → Guardrails**.

### Enterprise Decision Agent

An enterprise-customized Agent powered by **PydanticAI**, private knowledge retrieval and controlled business-data tools—designed to produce evidence-backed planning suggestions, decision support and risk alerts with human review.

### Observable Agent Runtime

A typed runtime with explicit tool contracts, session isolation, bounded execution loops, structured error feedback and inspectable traces. The goal is dependable automation, not a black-box chatbot.
